## What I found and built

The SDK (SDK/playtest_sdk) is a decorator-based playtesting library — @track_action, @track_state, @check_invariant — driven by a SwarmRunner that runs agent bots (random_walker, goal_seeker, chaos_tester), then runs detectors and generates an HTML report. Its bundled example is a toy 10×10 grid game.

The integration proves it works on your *real* game. I created:

- playtest/platformer_game.py — a headless adapter that reuses the actual Player, Level, Walker/Flyer/Jumper physics classes and drives them via a VirtualInput, one fixed 1/60 s timestep per step. Instrumented with the SDK's decorators + 3 real invariants (player_in_bounds, lives_nonnegative, velocity_finite). It plants one clearly-marked demo bug (a hole in the ground floor).
- playtest/run_platformer_playtest.py — runs SwarmRunner with a correctly-sized detector config and generates SDK/output/platformer_report.html.
- playtest/README.md — how to run it and what it proves.

## SDK issues I found and fixed (these are real viability problems)
