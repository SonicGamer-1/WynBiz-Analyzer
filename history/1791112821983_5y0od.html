Why it's broken (I confirmed it live):

There is no SDK/__init__.py, so SDK becomes a *namespace package*. The net effect is that the SDK gets loaded twice under two different names:

Concretely:
- SDK/example_game/game.py does from playtest_sdk import track_action, ... → the game's @track_action decorators bind to the top-level playtest_sdk.
- demo_runner.py uses SDK.playtest_sdk.SwarmRunner → the runner creates sessions from SDK.playtest_sdk.PlaytestSession.

PlaytestSession keeps its current session in a class-level threading.local() (_local). Since the two class objects are different, the decorators can never see the runner's session, so no actions are recorded and the swarm finds zero bugs → oob_bugs[0] raises IndexError.
